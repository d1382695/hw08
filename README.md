## 3. 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
因為 `"4"` 加上雙引號後屬於字串（`str`）型別，在 Python 中代表文字符號而非數值。Python 無法直接將數字金額除以字串（執行 `1220.0 / "4"` 會發生 `TypeError` 型別錯誤），因此必須先透過 `int("4")` 轉換為整數（`int`）型別的 `4`，才能進行除法分攤運算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
- **計算過程**：
  - 先扣折價券後的剩餘餐費：`1,200 - 100 = 1,100` 元
  - 再依剩餘餐費計算 10% 服務費：`1,100 × 0.10 = 110` 元
  - 應付總額會變成：`1,100 + 110 = 1,210` 元
- **差異原因**：題目規定服務費必須以「原始餐費 1,200 元」計算，因此服務費為 `120` 元，總額為 `1,220` 元；若改成先扣折價券再算服務費，折價券的 `100` 元也會被少算 10% 服務費（`100 × 0.10 = 10` 元），導致服務費減少為 `110` 元，應付總額因此比題目規定少了 `10` 元。
